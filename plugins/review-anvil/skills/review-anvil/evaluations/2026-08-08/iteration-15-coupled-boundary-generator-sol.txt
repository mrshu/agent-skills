Although `followlinks=False` blocks directory symlinks discovered below the root, it does not block this explicit-root case. The current test covers only the discovered-child case, leaving direct and glob-expanded directory-symlink matches able to traverse their targets.\n\n**Requested actions**\n\n- Reject directory-target symlinks for direct and glob-expanded matches while keeping file-symlink behavior unchanged.\n- Add tests for both directory-symlink inputs and an accepted file symlink to cover the boundary.\n\n<!-- review-anvil: id=RAV-RUN2-R1-F001 severity=medium area=filesystem-traversal -->"}
